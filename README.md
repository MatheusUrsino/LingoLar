# 🌎 LingoLar

LingoLar é uma plataforma para aprendizado de idiomas, atualmente em fase alpha, com foco em oferecer uma experiência simples e direta de estudo.

## ✨ Funcionalidades

- Cadastro e autenticação de usuários
- Estrutura de conteúdo para aprendizado de idiomas
- Persistência de dados em banco relacional

## 🛠️ Tecnologias utilizadas

- Next.js
- TypeScript
- Drizzle ORM
- PostgreSQL
- Tailwind CSS

## 🚀 Como rodar o projeto

```bash
# Clone o repositório
git clone https://github.com/MatheusUrsino/LingoLar.git

# Acesse a pasta do projeto
cd LingoLar

# Instale as dependências
npm install

# Configure as variáveis de ambiente (banco de dados, etc.)
cp .env.example .env

# Rode as migrations do banco
npm run db:migrate

# Rode o projeto
npm run dev
```
